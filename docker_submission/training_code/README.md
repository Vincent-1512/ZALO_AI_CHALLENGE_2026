# LifeMate – training code and solution description (Zalo AI Challenge 2026)

## Idea in one paragraph
Voice request -> **ASR** -> **LLM policy** -> tool calls executed through `zaic_tools.ToolEnv`. The LLM outputs one JSON action per step (a tool call or `stop`); the loop feeds each tool result back until `stop`, a repeated call, or the step limit (8). Prompts hold the tool catalog, the transcript(s) of the current and past user turns, and prior calls/results.

## Models
| Part | Model | Parameters | Notes |
|---|---|---|---|
| ASR | `vinai/PhoWhisper-large` fine-tuned (LoRA r=32 merged) | about 1.55 B (exact count: `saved_models/MANIFEST.json`) | BSD-3-Clause base |
| LLM | `Qwen/Qwen3-4B-Instruct-2507` + LoRA r=16, alpha=32 (merged for inference) | 4,022,468,096 | context used 8,192 tokens (hard limit 16,384) |

Total is below 6 B and the LLM is below 5 B (verified from safetensors headers by `scripts/merge_for_submission.py`, not by estimate). Inference is greedy (no sampling), seed 2026, fully offline.

## Data
- Competition train split (audio, requests, gold tool calls) plus the history-turn audio of each sample. Split by seed 2026: 80% train / 10% dev / 10% holdout.
- No synthetic data. ASR-noise augmentation of the training text only: some training prompts use ASR transcripts instead of the written request (`scripts/build_asr_train_data.py`).
- Download URLs (must stay unchanged after the deadline):
  - ASR model: https://huggingface.co/vincent1512/lifemate-phowhisper-large-ft
  - LLM adapter: https://huggingface.co/vincent1512/lifemate-qwen-adapter (created by `scripts/upload_adapter_hf.py`; confirm it exists and is public before submitting)

## Reproduction order (seeds in brackets)
1. `training/prepare_sft.py` -> SFT jsonl from the train split [2026].
2. ASR: `python training/finetune_asr.py --data-root <data> --base-model vinai/PhoWhisper-large --output-dir models/PhoWhisper-large-ft --epochs 4 --lr 1e-4 --batch-size 4 --grad-accum 4 --lora-r 32 --seed 2026 --train-seed 7` (WER on held-out dev audio 0.2469 -> 0.0921).
3. LLM stage 1: `training/train_lora.py` from scratch, QLoRA r=16/alpha=32, 3 epochs (1524 steps), max sequence 8,192 [2026]. **The exact original command is not preserved in this folder**; defaults are in `train_lora.py` and `configs/baseline.json` and must be confirmed before relying on this step.
4. LLM stage 2 (`train_noise`): warm start from the stage-1 adapter, 1 epoch, lr 2e-5, seed 2028, on training text where about half the ASR-noisy rows come from the base PhoWhisper-large transcripts. Full command lines: `notebooks/lifemate_vast_final.ipynb` (generated by `scripts/build_final_notebook.py`), which is the authoritative driver.
5. `scripts/merge_for_submission.py` -> `saved_models/`.
6. Evaluate: `training/evaluate_dev.py` (official scoring formula).

Known gap for reproducibility: stages 3 and 4 depend on checkpoint 1524 and on a GPU-hours budget (about 7 h per epoch on one RTX 3090). Bit-identical weights are not guaranteed across hardware.
